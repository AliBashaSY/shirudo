Contribute
==========

These pages are for developers who change shirudo itself: its code, its
tests, its build and this documentation. Start with
:doc:`/contribute/developer-guide` to build from a clone, then
:doc:`/contribute/develop-locally` to run the operator and a target on
one machine and take a package through its life, and
:doc:`/contribute/testing` to run the tests in the test VM that plays a
target. :doc:`/contribute/test-coverage` shows what the tests cover and
what they do not. Before you send a change, read
:doc:`/contribute/contributing` and :doc:`/contribute/coding-style`, and
read :doc:`/security/threat-model` first when the change touches a
security-relevant path.
