Start
=====

Start here if you are new to shirudo. The quickstart builds it, boots a
protected test target in a VM and takes one upatch through its whole
life. The next two pages explain the problem shirudo addresses and the
path an upatch takes from a kernel fix to a measured load. The
installation page and the quick guides then cover the first tasks:
installing the packages, writing an upatch, publishing a package and
attesting a target.
